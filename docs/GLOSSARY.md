# GridLock glossary

One name per idea, in every button, menu, title, tooltip, Help page and error.

| Term | Means | Not |
| --- | --- | --- |
| Desk | One set of connected displays, recognized by their serial numbers. Each desk keeps its own grids and palettes. | profile, setup, configuration, workspace |
| Display | One screen at a desk, built-in or external (Apple's word in System Settings). | monitor, screen (in UI text) |
| Grid | The columns and rows GridLock lays over a display, set per display per desk. | matrix, overlay (in UI text) |
| Cell | One rectangle of the grid. | square, tile, block |
| Show Grid | Put the grid over the display under the frontmost window, ready to place it. | grid overlay, grid mode |
| Selection | The cells chosen on the grid; the window will fill them. | spot, region, area |
| Palette | The row of layouts that drops down when a window is dragged to the top edge of a display. | drop zone, bar, menu |
| Layout | One palette thumbnail: a way of dividing a display (Halves, Columns × 3, Grid 3 × 2, or a custom layout). | pattern (in UI text), template, preset |
| Zone | One part of a layout; a window snaps into it. | region, slot, area |
| Snap | Move and resize a window into a zone or selection. | tile, place, dock |
| Count | How many columns, rows, or columns × rows a layout family has. | number, divisions |
| Gap | Space between snapped windows. | padding, gutter |
| Margin | Space between snapped windows and the display's edges. | inset, border |
| Undo Move | Put the last window GridLock moved back where it was. | revert, restore |
| Custom Layout | A layout the user draws in the layout editor. | user pattern |
| Arrangement | (Milestone 2) Several apps' windows snapped into zones at once, saved per desk. | workspace, scene |
| Access | The macOS permission GridLock needs to move other apps' windows. On macOS 27 it is listed under Privacy & Security › Device Control and Data Access. | accessibility permission (except when quoting older macOS) |
